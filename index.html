01 / 團體介紹

認識 Stray Kids

八個不同的聲音，組成一個無法被複製的團體。

Stray Kids · RUN IT 首爾場

做自己的音樂，
走自己的路。

Stray Kids（簡稱 SKZ）是 JYP Entertainment 旗下的韓國男子團體，於 2018 年正式出道， 由 Bang Chan、Lee Know、Changbin、Hyunjin、 Han、Felix、Seungmin 和 I.N 八位成員組成。

他們以強烈的音樂風格、鮮明的個人特色與充滿能量的舞台 表現受到關注。團體內的製作小組 3RACHA， 由 Bang Chan、Changbin 和 Han 組成， 參與多首作品的詞曲創作與製作。

對 Stray Kids 而言，音樂不只是跟隨既有的規則， 更是表達自我、探索可能性，以及不斷突破的方式。

02 / 歌曲概念

RUN IT 的精神

這不只是向前跑，更是決定自己要走向哪裡。

“

從首爾出發，
走向全世界。

〈RUN IT〉描繪 Stray Kids 從首爾出發、 走向世界舞台的成長歷程。 面對挑戰與限制，他們選擇持續前進， 追求更高的目標，拓展自己的可能性。

這首歌將一路累積的經驗與野心， 轉化成面向未來的宣言。 不是等待機會降臨，而是帶著自己的節奏繼續向前。

01 / 起點

從自己的起點出發

從首爾走向更廣闊的世界，象徵團體一路成長， 也代表不忘記初心，繼續探索新的可能。

02 / 動能

持續前進的推進力

銅管樂、行進鼓與世界節奏共同構成強烈的音樂動能， 讓整首歌帶有鮮明的氣勢與前進感。

03 / 突破

不讓自己停在原地

歌曲傳達突破困境、追求勝利與更高目標的意志， 而不是滿足於已經取得的成就。
